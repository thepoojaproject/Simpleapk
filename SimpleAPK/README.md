# Simple APK

A minimal Android app with GitHub Actions APK build automation.

## GitHub par chalane ka tarika

1. Is project ko GitHub repository me upload karo.
2. Repository ka default branch `main` rakho.
3. `Actions` tab me jao.
4. `Build APK` workflow automatically run hoga.
5. Build complete hone ke baad:
   - `Actions > Build APK > Artifacts` me APK milega.
   - `Releases` me bhi APK attach hoga.

No Android Studio is required for GitHub Actions build.
